# relevant-search-writing

## Output rules

- 條列優先，短句。
- 不用流程旁白。
- 不用反面轉折句。
- 不用教學口吻。

## Forbidden phrases

- 這篇要講…
- 接下來…
- 不是…而是…
- 不只…更…
- 關鍵是…
- 最重要的是…

## Required sections

1. 今日重點（3-6 點）
2. 名詞（最多 3 個）
3. 常見誤區（至少 2 點）
4. 可落地做法（2-4 點）
5. 一句話

## Style

- 正面表列。
- 每點只講一件事。
- 優先可驗證描述。
