# relevant-search-writing

## Hard style rules

- 開頭直接進內容，不描述「你要做什麼」。
- 先給讀者最小背景脈絡，再列重點。
- 只用短句條列，不用報告模板標題。
- 全文用正面直述句（主詞 + 動詞 + 結果）。
- 不用反面對照句型。
- 每條都要能單獨成立，讀者不需猜上下文。

## Output shape

- 先列 1-2 條 context（這段在講哪個章節/問題，為何現在值得看）。
- 再列 5-8 條重點內容（事實、判斷、做法混合）。
- 至少 1 條提到限制或適用邊界。
- 至少 1 條提到可執行做法。

## Forbidden phrases

- 這篇要講…
- 本文將…
- 我會先…
- 接下來…
- 不是…而是…
- 不只…更…
- 關鍵是…
- 最重要的是…
- 重點在…
- 這段重點…
- 同一…不同…（例：同一套搜尋引擎，進到不同產品會排出不同答案）
- 今日重點 / 名詞解釋 / 常見誤區 / 一句話總結
